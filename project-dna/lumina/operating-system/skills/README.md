# Lumina Skills

Dit is de **canonieke** skills map voor Lumina.

## Locatie
`project-dna/lumina/operating-system/skills/`

## Gebruik
Alle agents (Grok Build en Cursor) dienen bij voorkeur skills uit deze map te laden.

## Prioriteit
Zie `project-dna/lumina/AGENTS.md` → sectie "Skills" voor de prioritering.

## Onderhoud
- Skills worden centraal beheerd.
- Wijzigingen aan skills volgen het Recursive Self-Improvement Protocol.
- Tool-specifieke overrides (in `.cursor/skills/` of `.grok/skills/`) zijn alleen toegestaan als aanvulling.
