## Approval Twin (post-dates most analyses here)

From mid-2026 the **Approval Twin** is the user-trained human replacement *judgment* layer (ADR-0031, ADR-0032). Pre-Twin wording that treats permanent human approve/veto on every birth decision as eternal law is **superseded for judgment only**. Hard gates (constitution, sandbox, shadow, REAL PromotionGate) are unchanged.
